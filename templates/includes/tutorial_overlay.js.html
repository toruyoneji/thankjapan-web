{% comment %} playTutorialOverlay(id, holdMs, callback) - shows the #id overlay (see tutorial_overlay.css.html), holds it for holdMs, fades it out, then calls callback once the fade-out transition (0.3s, matching the CSS) finishes. Safe to call even if the element isn't on the page (calls callback immediately) so callers don't need to guard every use. playTutorialOverlayAuto(id, callback, opts) - 2026-09-22, added alongside the function above (not replacing it) after user feedback that translated overlay text (esp. de/fr/it) was being cut off before it could be read at the old fixed 2200/2500ms holds. Deliberately a SEPARATE function rather than changing playTutorialOverlay itself: only 6 call sites (4 flagged "highest priority" + 2 "medium priority" from that review) were migrated to this; the ~9 other existing playTutorialOverlay call sites ("low priority" in that review - short imperative nav hints like "Click 'Learn' below") were deliberately left untouched and keep their original fixed-ms timing exactly as before, with zero risk of this change affecting them. {% endcomment %}
